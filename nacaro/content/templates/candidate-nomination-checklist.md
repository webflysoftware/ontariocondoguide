## Before nominations open

- [ ] Confirm number of open seats and term lengths
- [ ] Publish nomination deadline and required forms
- [ ] Distribute eligibility requirements to owners
- [ ] Define equal format for candidate statements

## For each candidate

| Candidate | Unit | Nomination form complete | Eligibility verified | Statement received | Listed on ballot |
|-----------|------|--------------------------|----------------------|--------------------|------------------|
|           |      |                          |                      |                    |                  |
|           |      |                          |                      |                    |                  |

## Eligibility checks

- [ ] Owner in good standing requirement reviewed
- [ ] Occupancy or residency requirement reviewed
- [ ] Delinquency restriction reviewed if applicable
- [ ] Criminal background or other document restrictions reviewed where permitted by law

## Owner communication

- [ ] All candidates notified of acceptance on ballot
- [ ] Declined nominations documented
- [ ] Final ballot proof reviewed by board or inspector
